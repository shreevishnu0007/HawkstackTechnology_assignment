Hawkstack Technology Backend API

This project is a secure REST API built using:

Java
Spring Boot
Spring Security
Hibernate / JPA
MySQL

The application provides:

User Registration
User Authentication
Secure CRUD APIs
File Upload APIs
RESTful Architecture

Spring Boot 3
Spring Security
Hibernate / JPA

Maven
Lombok
JWT (Dependency Added)
